## 3. Technical SEO Issues Found (fixable now)

### 🔴 High Priority

1. **Pit Row one-sheet canonical mismatch**
   - Page serves at `/one-sheet/` but `<link rel="canonical">` points to `/one-sheet.html`
   - `/one-sheet.html` 301s to `/one-sheet/`, so canonical is self-referencing the redirect target incorrectly
   - **Fix:** change canonical to `https://pitrowmiami.com/one-sheet/`

2. **Dead URLs in Google's index (TOG)** — these pages return **404** but are/were in Google's index:
   - `/pricing` → 404
   - `/web-design` → 404
   - **Fix:** either restore these pages or 301-redirect them to relevant live pages (e.g. `/pricing` → `/services/`, `/web-design` → `/services/`)

3. **No structured data (JSON-LD) on TOG at all** — and only on Pit Row's homepage.
   - TOG: 0 pages have JSON-LD (LocalBusiness/Organization/Service/FAQ schema)
   - **This is the single biggest free SEO win available** — adding schema helps Google understand and feature your business.
   - **Fix:** add `Organization`/`LocalBusiness` schema site-wide + `Service` schema on services pages + FAQ schema where applicable

### 🟡 Medium Priority

4. **Pit Row one-sheet missing OG/Twitter share tags** — only the homepage + privacy/terms have them. One-sheet has none.
5. **TOG OG image is generic** (`og-default.png`) — should be per-page or at least brand-specific; consider updating to match new branding.

### 🟢 Good / Already Working
- Both sites: `robots.txt` correct, sitemap valid + reachable (HTTP 200)
- All key pages return 200; H1 count = 1 per page (correct)
- Titles + meta descriptions present on all pages (good length)
- Canonical correct on all pages EXCEPT Pit Row one-sheet
- `index, follow` robots meta everywhere
- Twitter card + OG tags present on most pages
