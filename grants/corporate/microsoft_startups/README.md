## Common Pitfalls to Avoid

### ❌ Critical Mistakes

1. **Describing Yourself as an Agency/Consultancy**
   - Microsoft excludes pure consulting firms
   - Frame as: "AI automation platform for SMBs"
   - "Software company with implementation services"
   - Never lead with "agency"

2. **Over $20M Raised**
   - Hard cutoff for the program
   - If you've raised less, emphasize early stage

3. **Company Older Than 7 Years**
   - Must be within 7 years of founding
   - The One Group (2024) is well within this

4. **No Clear Product**
   - Must demonstrate a product/platform
   - Not just services

5. **Missing Documentation**
   - Incorporation documents required
   - Have these ready before applying

### ⚠️ Important Notes

- Credits typically valid for 1-2 years
- Must be Azure customer (free tier OK)
- OpenAI credits are part of the package but subject to approval
- Microsoft may request quarterly updates on progress

### ✅ Pro Tips

1. **Emphasize Azure AI Differentiation**
   - Mention responsible AI practices
   - Reference Azure's enterprise security
   - Show interest in Microsoft ecosystem

2. **Highlight GitHub Integration**
   - If you use GitHub (even free), mention it
   - Shows you're in their ecosystem

3. **Prepare for the Interview**
   - Some applicants get screened via call
   - Know your numbers cold
   - Have clear growth story

4. **Follow Up**
   - If no response in 3 weeks, polite follow-up
   - LinkedIn outreach to Microsoft for Startups team
