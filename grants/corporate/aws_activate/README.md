## Step-by-Step Application Walkthrough

### Prerequisites (Do These First):

1. **Create AWS Account**
   - Go to https://aws.amazon.com
   - Use company email domain (not personal Gmail)
   - Add payment method (required even with credits)
   - Note your Account ID (12 digits)

2. **Prepare Company Materials**
   - Ensure website is live (minimum: landing page with value prop)
   - Create LinkedIn Company Page
   - Record 3-minute demo video (use Loom)
   - Draft one-pager PDF

3. **Find a Referrer (REQUIRED)**
   - AWS Activate requires an invitation from a partner
   - Options:
     * Join a startup accelerator (YC, Techstars, 500 Startups, etc.)
     * Contact a VC firm that partners with AWS
     * Reach out to AWS reps at startup events
     * Use a co-working space that's an AWS partner
   - **Tip:** Many Miami startup events have AWS presence

### Application Steps:

1. **Get Referral Code**
   - From accelerator, VC, or AWS partner
   - Without this, you CANNOT apply

2. **Apply Online**
   - URL: https://aws.amazon.com/activate
   - Use referral code
   - Select "Portfolio" tier for $100K credits

3. **Complete Application**
   - Paste company profile above
   - Upload demo video link
   - Provide traction numbers (even if small, be honest)
   - Link to LinkedIn Company Page

4. **Wait for Review**
   - Timeline: 2-4 weeks
   - May request additional info
   - Credits expire 2 years from issuance

## Common Pitfalls to Avoid

### ❌ Critical Mistakes

1. **No Referrer**
   - You CANNOT apply directly
   - Must come through partner organization
   - Solution: Join any accelerator or reach out to VCs

2. **Generic Use Case**
   - "We'll use EC2 for servers" is not compelling
   - Be specific about Bedrock, SageMaker, etc.
   - Show you understand AWS's AI offerings

3. **No LinkedIn Company Page**
   - Required for verification
   - Takes 5 minutes to create

4. **Personal Email Domain**
   - Use @theonegroup.ai, not @gmail.com
   - Looks unprofessional

5. **No Website**
   - Minimum viable landing page required
   - Can be Webflow, Carrd, or simple HTML

### ⚠️ Important Notes

- Credits expire 2 years from issuance
- Only cover services, not support plans
- Cannot be transferred between accounts
- AWS audits usage - misuse can result in clawback
- Credits apply automatically to bill

### ✅ Pro Tips

1. **Emphasize AI/ML**
   - AWS prioritizes AI-native startups
   - Highlight Bedrock, SageMaker usage

2. **Show Traction**
   - Even 3 paying customers is better than zero
   - Document pilot agreements

3. ** Miami Advantage**
   - Mention Miami tech scene growth
   - AWS has major presence in Florida

4. **Plan for Scale**
   - Show how credits enable growth
   - Not just "free compute"
