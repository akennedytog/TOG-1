# STEP-BY-STEP SUBMISSION INSTRUCTIONS

## NSF SBIR Phase I Proposal
## The One Group, LLC

---

## OVERVIEW

This guide provides complete step-by-step instructions for submitting the NSF SBIR Phase I proposal through the official channels: Grants.gov and Research.gov.

**Important:** NSF SBIR Phase I proposals must be submitted through Research.gov. Grants.gov is used only for the SF-424 forms.

---

## PHASE 1: PRE-SUBMISSION REQUIREMENTS

### Step 1.1: SAM.gov Registration (REQUIRED)

**Timeline:** Complete at least 4 weeks before submission deadline

**Process:**
1. Visit https://sam.gov
2. Create an account or log in
3. Navigate to "Register/Update Entity"
4. Complete entity registration:
   - DUNS Number (or request one from Dun & Bradstreet)
   - TIN/EIN
   - CAGE Code (will be assigned)
   - NAICS Codes: 541511 (Custom Computer Programming), 541512 (Computer Systems Design)
   - Business information and representations
5. Submit for validation (takes 2-8 business days)
6. Receive active SAM record with CAGE code

**Verification:**
- [ ] SAM record shows "Active" status
- [ ] CAGE code received
- [ ] Account has "Electronic Business Point of Contact" designated

**Troubleshooting:**
- Issues: Contact Federal Service Desk at 866-606-8221
- Status check: https://sam.gov/SAM/pages/public/statusTracker.jsf

---

### Step 1.2: Research.gov Account Setup

**Timeline:** Complete at least 3 weeks before submission

**Process:**
1. Visit https://www.research.gov
2. Click "Register" and create account
3. Verify email address
4. Complete profile:
   - Personal information
   - Institution affiliation (The One Group, LLC)
   - Role: Principal Investigator
5. Link to NSF ID (if previously had NSF awards) or request new NSF ID
6. Authorized Organizational Representative (AOR) must approve account

**Verification:**
- [ ] Account shows "Active" status
- [ ] AOR approval received
- [ ] Able to access "Proposal Preparation" module

---

### Step 1.3: FastLane Migration (If Applicable)

If you had a FastLane account:
1. Visit https://www.fastlane.nsf.gov
2. Follow migration instructions to Research.gov
3. Verify all previous awards transferred

If new to NSF:
- Skip this step; Research.gov is your primary platform

## PHASE 2: PROPOSAL PREPARATION

### Step 2.1: Initiate Proposal in Research.gov

**Process:**
1. Log into Research.gov
2. Navigate to "Proposal Preparation"
3. Click "Create New Proposal"
4. Select:
   - Funding Opportunity: "Small Business Innovation Research (SBIR) Program - Phase I"
   - Program Solicitation: NSF 24-XXX (check current year)
   - Proposal Type: "Research"
5. Complete Cover Sheet:
   - Title: "Autonomous AI Agent Platform for SMB Operations"
   - Start Date: [6 months from award date]
   - Duration: 6 months
   - Requested Amount: $295,000

**Save frequently!** Research.gov auto-saves but manual saves recommended.

## PHASE 4: REVIEW AND VALIDATION

### Step 4.1: Run Proposal Checks

**Location:** Research.gov → Validate Proposal

**Instructions:**
1. Click "Check Proposal"
2. Review validation report
3. Address any errors or warnings:
   - Errors MUST be fixed before submission
   - Warnings should be reviewed

**Common Issues:**
- Missing required fields
- Budget calculation errors
- Document upload failures
- Page limit exceeded

---

### Step 4.2: Final Review Checklist

**Content Review:**
- [ ] Project Summary accurately reflects proposal
- [ ] Technical approach addresses solicitation requirements
- [ ] Commercialization plan is comprehensive
- [ ] Budget is justified and reasonable
- [ ] Timeline is achievable
- [ ] Team qualifications are documented

**Format Review:**
- [ ] All PDFs display correctly
- [ ] Page limits observed
- [ ] Fonts and margins compliant
- [ ] No password protection on PDFs
- [ ] File names are clear (not "document1.pdf")

**Administrative Review:**
- [ ] SAM registration active
- [ ] CAGE code entered correctly
- [ ] DUNS number accurate
- [ ] All senior personnel registered
- [ ] AOR has access and approval authority

---

## PHASE 5: SUBMISSION

### Step 5.1: Submit to AOR

**Location:** Research.gov → Submit

**Instructions:**
1. Click "Submit to AOR" (Authorized Organizational Representative)
2. System routes to AOR for approval
3. AOR reviews and either:
   - Returns for corrections
   - Approves and submits to NSF

**Communication:**
- Notify AOR that proposal is ready
- Provide deadline information
- Be available for questions

---

### Step 5.2: AOR Submission to NSF

**AOR Actions:**
1. Reviews proposal in Research.gov
2. Verifies SAM registration
3. Confirms budget accuracy
4. Submits to NSF
5. System generates:
   - NSF Proposal ID
   - Submission confirmation email
   - Proposal Control Number (PCN)

---

### Step 5.3: Confirm Submission

**Verification Steps:**
1. Check email for submission confirmation
2. Log into Research.gov
3. Navigate to "Submitted Proposals"
4. Verify proposal shows "Submitted" status
5. Note NSF Proposal ID and PCN
6. Save confirmation documentation

**Documentation:**
- [ ] Submission confirmation email
- [ ] Proposal ID recorded
- [ ] PCN recorded
- [ ] Date/time of submission noted

---

## POST-SUBMISSION

### Step 6.1: Monitor Status

**Timeline:** Check weekly until decision

**Process:**
1. Log into Research.gov
2. Check "Submitted Proposals"
3. Review status updates:
   - "Submitted" - Awaiting review
   - "In Review" - Panel review in progress
   - "Recommended for Award" - Positive decision pending
   - "Declined" - Not funded

### Step 6.2: Respond to Requests

**Possible Requests:**
- Budget revisions
- Clarification questions
- Additional documentation

**Response Time:** Typically 5-10 business days

### Step 6.3: Prepare for Phase II

**If Funded:**
- Receive official award notification
- Complete post-award requirements
- Begin project work
- Prepare for Phase II application (Month 5)

**If Not Funded:**
- Receive reviewer comments
- Consider resubmission
- Pursue alternative funding
- Update commercialization plan

## APPENDIX: COMMON ERRORS TO AVOID

1. **SAM Registration Expired** - Check status 2 weeks before
2. **Page Limit Exceeded** - Strictly enforced, automatic rejection
3. **Incorrect Funding Opportunity** - Verify current solicitation
4. **Missing Budget Justification** - Required even if obvious
5. **Unauthorized AOR** - Ensure AOR has current authority
6. **Last-Minute Submission** - Technical failures happen
7. **Incomplete Pilot LOIs** - Required for Phase I
8. **Unclear Commercialization Path** - NSF evaluates business viability
