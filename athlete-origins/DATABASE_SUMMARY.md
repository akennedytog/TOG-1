## Data Quality Indicators

Each profile has a data quality badge:
- **🟢 High** - Complete profile with verified stats, high school, achievements
- **🟡 Medium** - Good profile with some missing details
- **🟠 Low** - Basic profile, needs more research
- **⚪ Scraped** - Automated data from Wikipedia
