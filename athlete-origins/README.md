# Athlete Origins

A website that lists celebrities and famous people with their high school sports stats.

## The Concept

Before they were famous, they were high school athletes. This site captures that origin story.

## MVP Features

- [x] Searchable database of celebrities
- [ ] HS sports stats per person
- [ ] Comparison tools
- [ ] "What If" they went pro analysis
- [ ] Social sharing cards
- [ ] AI-generated bios

## Tech Stack

- Python (data scraping/enrichment)
- Static site generator (fast, cheap hosting)
- JSON data files
- Tailwind CSS (styling)

## Data Sources

1. Wikipedia (primary)
2. MaxPreps (verified stats)
3. AI enrichment (gaps filling)
4. Crowdsourced corrections

## Target Launch

100 profiles MVP
