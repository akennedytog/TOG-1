# BabyNest

**AI-Powered Baby Financial Planning App**

A Next.js + TypeScript application that guides new parents through the complex financial, insurance, and legal landscape of having a child. Unlike parenting apps focused on development milestones, BabyNest focuses on financial milestones — from insurance enrollment deadlines to 529 plan optimization.

## 🎯 Problem Solved

New parents face time-sensitive financial decisions with costly consequences:
- Missed 60-day insurance enrollment = $20,000+ in uncovered bills
- Wrong 529 plan choice = thousands in lost tax savings
- Information exists but is fragmented across 50 states and dense government sites

## ✨ Key Features

### AI-Powered Guidance
- **State-Aware Recommendations:** Automatically detects location, provides relevant deadlines
- **Insurance Decoder:** Translates plan jargon into actionable deadlines
- **529 Plan Optimizer:** Compares state tax benefits, ranks options
- **Timeline-Based Tasks:** "Do this now" vs "Do this later" prioritized by urgency

### Core Functionality
- **Financial Timeline:** Visual pregnancy-to-age-5 journey with key dates
- **Budget Tracker:** Category-based spending with smart suggestions
- **Savings Goals:** 529 plans, emergency fund, childcare costs
- **Smart Task Manager:** Auto-prioritized by deadline and impact

### Technical Stack
- **Frontend:** Next.js 14 App Router, TypeScript, Tailwind CSS
- **UI Components:** Shadcn/ui with custom glassmorphism design
- **Animations:** Framer Motion with custom providers
- **Backend:** Supabase (real-time data, auth, storage)
- **Database:** PostgreSQL via Supabase
- **Deployment:** Production-ready with comprehensive audit
