# Boot Instructions

This file outlines the startup sequence for the workspace agent.

1. Read `SOUL.md` (agent persona).
2. Read `USER.md` (user preferences).
3. Read today's diary in `memory/YYYY-MM-DD.md`.
4. Read `MEMORY.md` (long-term memory).
5. Initialize scheduled services (e.g., tweet-scheduler via PM2).
6. Await user commands.
