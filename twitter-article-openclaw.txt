2/ THE SOLUTION: MULTI-LLM ROUTING

Instead of one expensive model, we route tasks across 4 LLMs based on complexity.

Simple rule: Use the cheapest tool that can do the job.

---

3/ OUR $0 AI STACK

• Ollama (local) → Routine tasks: $0.00
• n8n → Automation: $0.00
• Kimi K2.5 → Code review: $0.003/1K tokens
• Claude 3.5 → Complex reasoning: $0.015/1K tokens
• GPT-4o → Vision tasks: $0.025/1K tokens

TOTAL: ~$150/month

Others pay: $2,000+

4/ THE DECISION TREE

Summarize → Ollama (free)
Code review → Kimi (cheap)
Complex reasoning → Claude ($)
Vision tasks → GPT-4o ($$)
Emergency → GPT-4 ($$$)

Match the tool to the task.
