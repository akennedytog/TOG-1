# Truth Dashboard

An AI-powered dashboard that classifies global news into Confirmed, Credible Rumors, and False Rumors, updated hourly.

## Vision
Provide a single source of truth to combat misinformation in ongoing conflicts and events.

## Tech Stack
- Backend: Node.js, Express, SQLite, node-cron, TypeScript
- Frontend: React, TypeScript
- Shared: TypeScript interfaces

## Setup

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm start
```
