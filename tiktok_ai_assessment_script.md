## Production Notes

**Length:** 15-30 seconds (sweet spot: 21 seconds)
**Aspect ratio:** 9:16 (1080x1920)
**Text size:** Large enough to read on mobile
**Captions:** Always add auto-captions
**Hook:** Must grab attention in first 1 second
**CTA:** Clear and direct at the end

---

## Tools You Can Use (All Free)

1. **CapCut** (mobile or desktop) — Free editing, templates, text animations
2. **Canva** — Animated text templates, stock footage
3. **Screen Studio** (Mac) — Beautiful screen recordings ($0 trial)
4. **OBS** (free) — Basic screen recording
5. **TikTok's native text-to-speech** — Built in, no extra tools

---

## Quick Start (15 mins, zero recording)

1. Screenshot key parts of your AI Assessment page
2. Import to CapCut
3. Add trending audio
4. Use "Auto captions"
5. Add text overlays with key points
6. Export 1080x1920
7. Post with caption template above

**Done.**
