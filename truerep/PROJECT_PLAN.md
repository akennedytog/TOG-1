# Anonymous Professional Reputation Platform - Project Plan

## Project: "TrueRep" (Working Name)

### Overview
Anonymous, verified professional reputation platform. Users verify employment via company email, build anonymous profiles, receive peer ratings.

---

## Phase 1: MVP Prototype

### Goals
- Demonstrate core concept
- Test verification flow
- Validate UI/UX
- Get feedback before legal/technical deep dive

### Features (MVP)
1. Landing page explaining concept
2. Simple profile creation (mock verification)
3. Anonymous profile view (ratings, tags)
4. Basic rating submission (mock)
5. Search/browse profiles

### Tech Stack
- HTML/CSS/JS (static site)
- Netlify hosting
- Mock data (JSON)
- No backend yet

---

## Phase 2: Legal Research

### Deliverables
