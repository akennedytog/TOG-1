# createText

Creates a new, empty text node.

## Signature [​](https://developers.figma.com/docs/plugins/api/properties/figma-createtext/\#signature "Direct link to Signature")

### [createText](https://developers.figma.com/docs/plugins/api/properties/figma-createtext/)(): [TextNode](https://developers.figma.com/docs/plugins/api/TextNode/)

## Remarks [​](https://developers.figma.com/docs/plugins/api/properties/figma-createtext/\#remarks "Direct link to Remarks")

By default, parented under `figma.currentPage`. Without setting additional properties, the text has no characters. You can assign a string, to the [`characters`](https://developers.figma.com/docs/plugins/api/properties/TextNode-characters/) property of the returned node to provide it with text.

Create a styled 'Hello world!' text node

```ts
(async () => {
  const text = figma.createText()

  // Move to (50, 50)
  text.x = 50
  text.y = 50

  // Load the font in the text node before setting the characters
  await figma.loadFontAsync(text.fontName)
  text.characters = 'Hello world!'

  // Set bigger font size and red color
  text.fontSize = 18
  text.fills = [{ type: 'SOLID', color: { r: 1, g: 0, b: 0 } }]
})()
```
