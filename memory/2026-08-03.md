## Google Drive PPTX Access Technique (2026-08-03)

**Problem:** Need to read a PPTX file from Google Drive when:
- Google Slides API isn't OAuthed
- Google Drive export only works for native Google Workspace files
- No download action in the googledrive connector catalog

**Solution that worked:**
1. Get the OAuth access token from the connector's auth store (found in `~/.openclaw/agents/main/agent/openclaw-agent.sqlite` under the googledrive connection profile)
2. Use the Google Drive API directly: `GET https://www.googleapis.com/drive/v3/files/{fileId}?alt=media` with `Authorization: Bearer {token}`
3. Save the binary response to a local file
4. Extract text using Python's `python-pptx` library

**Key insight:** The connector stores OAuth tokens in the SQLite database. For googledrive connections, the token is stored as a JSON blob in the `store_json` column. The access token can be extracted and used for direct API calls that the connector doesn't support.

**Lesson:** When a connector doesn't have the action you need, you can often use the stored OAuth token to call the underlying API directly.

- `astro.config.mjs` imported `@tailwindcss/vite` but it wasn't installed

**3. Tailwind CSS not processing — CSS missing from build output**
- The CSS was referenced as a static `<link href="/src/styles/global.css">` in the layout
- Astro doesn't process static CSS references — only CSS imported via JS/astro imports
- Fix: Changed to `import "@/styles/global.css"` in BaseLayout.astro
- Result: CSS now hashed as `_astro/BaseLayout.Ded21fsO.css` in build output

**4. @astrojs/tailwind v6.0.2 incompatible with Tailwind v4**
- `@astrojs/tailwind` expects Tailwind v3, but v4 is installed
- Fix: Removed `@astrojs/tailwind`, used `@tailwindcss/postcss` directly with PostCSS config

**5. PostCSS looking for `tailwindcss` as a file path**
- `@import "tailwindcss"` in global.css was being interpreted as a file path by PostCSS
- Fix: Changed to `@import "tailwindcss"` (same syntax but PostCSS config was missing)
- Actually needed: proper PostCSS config with `@tailwindcss/postcss` plugin

**6. Astro 7 + Node 24 compatibility — cookie module CJS issue**
- `default-prerenderer.js` failed with `ERR_NAMESPACE_NOT_DEFINED` on `cookie` package
- `cookie` v0.6.0 is CJS, Node 24 is stricter about named imports from CJS
- Fix: Patched `node_modules/astro/dist/runtime/server/cookies.js` to use `createRequire` for the cookie import
- Alternative: Could pin cookie to v0.7.0+ (ESM) or downgrade Node

**7. Netlify SSR function build failed**
- `@astrojs/netlify` adapter tried to bundle SSR functions
