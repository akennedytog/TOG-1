### Week-by-Week Checkbox Fix (9:14 PM)
**Problem:** Checkboxes on week-by-week tracker not working - clicking did nothing
**Root Cause:** `onClick` handler on parent `<li>` element conflicting with Checkbox's `onCheckedChange`, causing double-toggle
**Fix:**
- Removed `onClick` from `<li>` element
- Added proper `<label>` with `htmlFor` matching checkbox `id`
- Added `cursor-pointer` to checkbox and label elements
- Works with no double-toggling
