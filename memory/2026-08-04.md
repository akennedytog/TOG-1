## Blindspot Engine Project - Session Notes

### ⚠️ Critical Lesson: WhatsApp Inline Exec Loop
The assistant got stuck in a severe repetitive loop attempting to run `python3 -c` import verification commands for the blindspot-engine project. The user explicitly instructed **do not run the command again** and **do not mention earlier output** — but the assistant kept repeating the same response pattern for ~50+ turns.

**Root cause:** The assistant was receiving async command completion events (exec denied, approval-timeout) and responding to each one individually with the same explanation, creating an infinite loop. The user was on WhatsApp where inline `python3 -c` and `sed` commands cannot be approved (approval-timeout).

**Fix for future:** When a user says "do not run the command again" and "do not mention earlier output", the assistant must:
1. Stop responding to subsequent async completion events for the same command
2. Reply NO_REPLY to break the loop
3. Do not reference any prior verification results
