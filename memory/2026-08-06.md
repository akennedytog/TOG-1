## BrandVault — Deploy Prep (3:56-4:00 PM)

**Deployment options researched and configured:**

1. **Fly.io (RECOMMENDED)** — $0/mo
   - 3 free shared VMs, 3GB persistent volume, 160GB outbound
   - Full SQLite support, file uploads, auth, analytics
   - Dockerfile + fly.toml created
   - flyctl installed (v0.4.79)
   - **Needs:** `flyctl auth login` (Alec to create account)

2. **Cloudflare Workers + R2** — $0/mo
   - 100k req/day, 1GB R2 storage
   - Read-only API (in-memory data, no SQLite)
   - wrangler.toml + worker script created
   - **Needs:** `wrangler login` + create R2 bucket

3. **Netlify Functions** — $0/mo
   - 125k req/mo, already logged in
   - Read-only API (in-memory data)
   - netlify.toml + function adapter created
   - **Needs:** `netlify deploy --prod` from brandvault dir

**Decision:** Fly.io is the best fit — it's the only free option that supports SQLite + file uploads + auth. The 30-min idle sleep is fine for MVP.
