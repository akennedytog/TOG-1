## BabyNest Audit (1:30 PM - 1:49 PM ET)

Started auditing the BabyNest Next.js app (getbabynest.com) for issues. Discovered:

### Key Findings
- **Main codebase** is at `~/babynest` — it's the more complete version (420 source files, has hooks, middleware, providers)
- **`babynest-full-fixed`** is a subset (149 files), not a superset — it has some improvements (LegalFooter in layout, better SEO metadata) but is missing hooks, middleware, providers
- **Deployed site is a hybrid** — shows LegalFooter (from full-fixed) but old navLinks/social links (from main)
- **Netlify site IDs:** babynest12 (2235de1c-5815-42d5-85f9-b07da8e7899c) for getbabynest.com, theonegroup (a70736d7-9776-4d0e-9908-0f5402a5e16d) for theonegroup.info

### Critical Issues Found
1. **OG tags point to localhost:3000** — `NEXT_PUBLIC_SITE_URL` not set on Netlify, layout.tsx has hardcoded metadata
2. **No robots.txt or sitemap.xml** — both return 404
3. **Social links are placeholder `#`** — Twitter, Instagram, LinkedIn all link to nowhere
4. **No canonical URL** — missing `<link rel="canonical">`
5. **Missing env vars on Netlify** — only 13 set, missing `NEXT_PUBLIC_SITE_URL` and `NEXT_PUBLIC_APP_URL`
6. **Layout.tsx needs SEO upgrade** — missing metadataBase, title.template, keywords, robots meta
7. **LegalFooter not in layout.tsx source** — deployed site shows it but source doesn't import it
8. **next.config.js has localhost in image domains**

### Fix Plan Created
Phase 1: Set env vars, update layout.tsx, add robots.txt/sitemap.xml, fix social links
Phase 2: Deploy to Netlify
Phase 3: Verify OG tags, robots.txt, all pages, Lighthouse audit

### Key Lesson
The "full-fixed" directory name was misleading — it's a partial snapshot, not the complete fixed version. The main `babynest` dir is the real source of truth. Need to cherry-pick improvements from full-fixed (layout.tsx SEO, LegalFooter) rather than replacing wholesale.
