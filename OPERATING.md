# The One Group OpenClaw Integration

## Mission
Deploy AI automation systems that small businesses actually use.

## Company Values
1. **Results over Hype** - Show, don't tell
2. **Speed over Perfection** - Ship fast, iterate
3. **Cost-Conscious** - Free tools first, scale intentionally
4. **Transparency** - Building in public, documenting everything

## Operating Principles

### Lead Management
- **Inquiry → Response:** < 2 hours
- **Response → Call:** < 48 hours
- **Call → Proposal:** < 1 week
- **Proposal → Close:** < 2 weeks

### Client Work
- **Discovery:** 1-2 calls
- **Audit:** 3-5 days
- **Implementation:** 2-4 weeks
- **Training:** 4-8 sessions
- **Support:** 30 days included

### Content Engine
- **Twitter:** 2x daily
- **Blog:** 2x weekly
- **Newsletter:** 1x weekly
- **Case Studies:** 1x monthly

### Financial Discipline
- **Burn Rate:** < $2k/month initially
- **Revenue Target:** $25k MRR by Month 6
- **Pricing:** No discounts > 10%
- **Payment:** 50% upfront, 50% on delivery

## Automation Rules
1. **Automate before hiring** - Use agents, not employees
2. **Document before automating** - SOPs first
3. **Measure everything** - Analytics for all systems
4. **Iterate weekly** - Review and improve

## Decision Framework
**High Impact + Low Effort = Do First**
**High Impact + High Effort = Plan**
**Low Impact + Low Effort = Batch**
**Low Impact + High Effort = Don't**

## Communication Standards
- **Slack:** Internal only
- **Email:** Client communication
- **Calendly:** All scheduling
- **Loom:** Async explanations
- **Notion:** Documentation
- **Twitter:** Public updates

## Quality Checklist
Before shipping anything:
- [ ] Tested end-to-end
- [ ] Documented (SOP created)
- [ ] Monitored (metrics tracked)
- [ ] Handoff ready (can delegate)

## Weekly Review
Every Sunday:
1. Review metrics (leads, closes, revenue)
2. Check content performance
3. Identify blockers
4. Plan next week
5. Update MEMORY.md

## Monthly Review
First of month:
1. Financial review (P&L)
2. Pipeline analysis
3. Client satisfaction check
4. Goal progress review
5. Strategy adjustment

## Annual Review
Q4 each year:
1. Full business audit
2. Market position analysis
3. Service portfolio review
4. Pricing optimization
5. Growth planning
