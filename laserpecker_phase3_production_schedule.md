# LaserPecker LP4 Phase 3 - Weekly Production Schedule

Objective: Maximize throughput by batching setup by LP4 mode (IR/Rotary first, then Diode), while preserving rush capacity.

## Weekly Rhythm

### Monday - IR + Rotary Batch A (Tumblers)
- SKUs: TB-01, TB-02, TB-06
- Tasks:
  - Prep blanks and mask/fixture setup
  - Run all single tumbler jobs
  - QC and package same day
- Capacity target: 20-30 units/day

### Tuesday - IR Batch B (Pet + Compact)
- SKUs: PT-01, PT-02, PT-03, WD-01
- Tasks:
  - Pet tag run in shape batches
  - Bridal mirrors in one fixture cycle
  - Print packing slips and batch mailers
- Capacity target: 35-50 units/day

### Wednesday - Diode Batch A (Boards)
- SKUs: CB-01, CB-02
- Tasks:
  - Board sanding/prep and alignment jigs
  - Run standard board engraving
  - Oil/finish and cure staging
- Capacity target: 10-16 units/day

### Thursday - Diode Batch B (Bundles + Wedding Tags)
- SKUs: CB-03, CB-04, WD-02
- Tasks:
  - Realtor/housewarming bundle assembly
  - Wedding tag name-list engraving batches
  - Bundle packaging + insert cards
- Capacity target: 8-14 bundles/day

### Friday - Bulk/Corporate Day
- SKUs: TB-03, TB-04, TB-05 + overflow from week
- Tasks:
  - Logo job setup and approval checks
  - Groomsmen/couple set assembly
  - B2B sample and pilot production
- Capacity target: 6-12 bundle jobs/day

### Saturday - Content + Maintenance + Catch-Up
- Film 2 product videos and 1 packaging video
- Deep clean machine lenses/rails and inspect rotary setup
- Catch up rush orders and remake defects

### Sunday - Admin + Planning
- Review Etsy conversion and ad spend
- Raise prices on winners (+$2 to +$4)
- Pause low-converting SKUs and refresh thumbnails

## Daily Time Blocks
- 8:00-9:00 AM: Order triage, proofs, customer messages
- 9:00-12:00 PM: Main production batch
- 12:00-1:00 PM: QC + lunch
- 1:00-4:00 PM: Secondary batch + packaging
- 4:00-5:00 PM: Shipping labels + post office drop
- 5:00-5:30 PM: Next-day material prep

## Rush Order Rule
- Hold 20% daily capacity for rush jobs.
- Cutoff: Rush orders placed by 1:00 PM enter same-day production.

## Quality Control Checklist
- Verify spelling against order notes before engraving.
- Inspect depth/contrast consistency under bright light.
- Photograph each finished custom item before packing.
- Include care card + thank-you insert in every shipment.
