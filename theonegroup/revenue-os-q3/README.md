# The One Group Revenue OS (Q3)

This is a practical operating system to grow `theonegroup.ai` using your installed stack:
- `open-seo`
- `chrome-devtools-mcp`
- `langflow`
- `codebase-memory-mcp`

## Goal
Turn audits into implementation projects and implementation projects into recurring retainers.

## Core Targets (first 30 days)
- 40 outbound touches per business day
- 20 discovery calls booked
- 8 completed paid audits
- 3 implementation closes
- 2 retainer closes

## Revenue Math (conservative)
- 8 audits x $1,500 average = $12,000
- 3 implementation projects x $5,000 average = $15,000
- 2 retainers x $2,000 MRR = $4,000 MRR
- Month 1 cash: $27,000 + $4,000 MRR added

## File Guide
- `OFFER_STACK.md`: products, pricing, and upsell flow
- `ICP_AND_POSITIONING.md`: who to target and how to message
- `OUTBOUND_PLAYBOOK.md`: outbound scripts and cadence
- `SALES_CALL_PLAYBOOK.md`: discovery-to-close process
- `DELIVERY_PLAYBOOK.md`: fulfillment SOP by tool
- `THIRTY_DAY_LAUNCH_PLAN.md`: day-by-day execution schedule
- `WEBSITE_COPY_BLOCKS.md`: copy ready for landing pages
- `templates/proposal-template.md`: fast proposal structure
- `templates/KPI_SCOREBOARD.csv`: daily dashboard template

## Weekly Cadence
- Monday: list building + campaign launch
- Tuesday to Thursday: outbound + calls + proposals
- Friday: delivery, case-study extraction, pipeline cleanup

## Non-negotiables
- No custom proposal before a paid audit or strategy call.
- Every call ends with a clear next step and date.
- Every delivery includes an implementation roadmap and retainer offer.
