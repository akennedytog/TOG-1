# A&P Audit Support Package — F26/F27

**Purpose:** Respond to the internal audit request for A&P activity plans and activation lists (Consumer Promo, Buy the Barrel, Branded Samples) for F26 and F27 through July 2026.

## Contents

| File | What it is |
|------|-----------|
| `AP_AUDIT_RESPONSE_EMAIL.md` | Draft response email to the auditor (fill in name/date) |
| `ACTIVITY_PLAN_TEMPLATE.csv` | Annual activity plan — one row per planned activity |
| `ACTIVATION_LIST_TEMPLATE.csv` | Detailed activation list — one row per activation |

## How to use

1. **Send the response email** (or adapt it) to acknowledge the request and confirm a delivery date.
2. **Fill `ACTIVITY_PLAN_TEMPLATE.csv`** with the planned activities for F26 and F27 (from your real off-MRM-record working files).
3. **Fill `ACTIVATION_LIST_TEMPLATE.csv`** with the actual activations that took place in the period.
4. Send both to the auditor in their preferred format (Excel/CSV).

## Notes
- All spend/activity data must come from **real records** — do not fabricate figures for an auditor.
- The `MRM Recorded?` column in the activation list helps the auditor reconcile off-MRM files against MRM.
- Confirm the auditor's preferred format and any spend threshold before finalizing.
