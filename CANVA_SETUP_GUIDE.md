## 🎬 VIDEO PRODUCTION CHECKLIST

### For Each Video:

1. **Screen Record** (OBS - free)
   - Record THE/dashboard.html
   - Record content-pipeline folder
   - Record terminal showing scripts

2. **Voiceover** (your phone or computer mic)
   - Read scripts from TIKTOK_STRATEGY.md
   - Record in quiet space
   - Use Audacity (free) to remove background noise

3. **Edit in CapCut** (free)
   - Import screen recording
   - Add voiceover
   - Add text overlays (using specs above)
   - Add music (CapCut has free library)
   - Export 1080x1920, 60fps

4. **Post to TikTok**
   - Use trending sounds if possible
   - Add hashtags from tiktok-content-calendar.json
   - Post at optimal times (9am, 3pm, 7pm)

## 🎤 VOICEOVER TIPS

### Recording Setup:
- Use iPhone Voice Memos or Audacity
- Quiet room, no echo
- Speak clearly, moderate pace
- Use pop filter or sock over mic

### Script Format:
Each video script in TIKTOK_STRATEGY.md is optimized for:
- 60-90 seconds
- Natural pauses
- Emphasis on key words
- Clear CTA at end

### Editing:
- Remove "um" and dead air
- Normalize audio levels
- Add slight background music (low volume)
