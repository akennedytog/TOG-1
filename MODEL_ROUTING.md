# Model Routing & Cost Rules

**Canonical Source:** `routing-config.json`  
**Version:** 5.2 (updated 2026-08-01)

## Core Policy

Cost first, quality guarded. Use the free Ollama Cloud models by default; escalate through paid fallbacks only when the free models are unavailable.

- **Primary (all interactive sessions, crons, heartbeats):** `ollama/deepseek-v4-flash:cloud`
    - DeepSeek V4 Flash via Ollama Cloud; not OpenRouter
- **Fallback 1:** `ollama/gpt-oss:20b-cloud` (auto-fallback if primary is down)
- **Fallback 2:** `openrouter/moonshotai/kimi-k3` (when both Ollama models fail)
- **Fallback 3:** `openrouter/openai/gpt-5.6-sol` (second paid fallback)
- **Utility (last-resort emergency):** `openrouter/openai/gpt-5.6-luna`
- **Local batch (direct API from scripts — Arlo, Iris):** ollama/llama3.1:latest ollama/qwen3-coder:latest
