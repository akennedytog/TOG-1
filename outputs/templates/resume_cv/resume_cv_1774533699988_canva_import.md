# Canva Import Instructions: Modern Resume/CV Template

## Template Details
- **Name:** Modern Resume/CV Template
- **Category:** document
- **Style:** clean_professional
- **Colors:** #2c3e50, #ecf0f1, #3498db

## Sizes to Create
- 794x1123px (3 pages)

## Steps to Import to Canva

1. **Create New Design**
   - Go to canva.com
   - Click "Create a design"
   - Select "Custom size" and enter: 794x1123px

2. **Set Up Color Palette**
   1. Add color: #2c3e50
   2. Add color: #ecf0f1
   3. Add color: #3498db

3. **Add Required Elements**
   - sections
   - progress bars
   - icons
   - timeline

4. **Style Guidelines**
   - Use clean professional style
   - Maintain consistent spacing
   - Use brand-appropriate fonts

5. **Export for Selling**
   - File > Download > PDF Print
   - Also export as: PNG (for previews)
   - Save to: /Users/aleckennedy/.openclaw/workspace/outputs/templates/resume_cv/
