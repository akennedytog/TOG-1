# Canva Import Instructions: Professional Business Card

## Template Details
- **Name:** Professional Business Card
- **Category:** print
- **Style:** corporate_elegant
- **Colors:** #1a1a1a, #f5f5f5, #c9a227

## Sizes to Create
- 1050x600px (2 pages)

## Steps to Import to Canva

1. **Create New Design**
   - Go to canva.com
   - Click "Create a design"
   - Select "Custom size" and enter: 1050x600px

2. **Set Up Color Palette**
   1. Add color: #1a1a1a
   2. Add color: #f5f5f5
   3. Add color: #c9a227

3. **Add Required Elements**
   - logo placeholder
   - contact info
   - qr code

4. **Style Guidelines**
   - Use corporate elegant style
   - Maintain consistent spacing
   - Use brand-appropriate fonts

5. **Export for Selling**
   - File > Download > PDF Print
   - Also export as: PNG (for previews)
   - Save to: /Users/aleckennedy/.openclaw/workspace/outputs/templates/business_card/
