## Steps to Import to Canva

1. **Create New Design**
   - Go to canva.com
   - Click "Create a design"
   - Select "Custom size" and enter: 1080x1920px

2. **Set Up Color Palette**
   1. Add color: #FF6B9D
   2. Add color: #C44569
   3. Add color: #F8B500

3. **Add Required Elements**
   - stickers
   - text animations
   - masks
   - filters

4. **Style Guidelines**
   - Use trendy aesthetic style
   - Maintain consistent spacing
   - Use brand-appropriate fonts

5. **Export for Selling**
   - File > Download > PDF Print
   - Also export as: PNG (for previews)
   - Save to: /Users/aleckennedy/.openclaw/workspace/outputs/templates/story_templates/
