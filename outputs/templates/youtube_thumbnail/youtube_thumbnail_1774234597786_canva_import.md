# Canva Import Instructions: YouTube Thumbnail Pack

## Template Details
- **Name:** YouTube Thumbnail Pack
- **Category:** youtube
- **Style:** bold_trendy
- **Colors:** #FF0000, #FFFFFF, #000000

## Sizes to Create
- 1280x720px (10 pages)

## Steps to Import to Canva

1. **Create New Design**
   - Go to canva.com
   - Click "Create a design"
   - Select "Custom size" and enter: 1280x720px

2. **Set Up Color Palette**
   1. Add color: #FF0000
   2. Add color: #FFFFFF
   3. Add color: #000000

3. **Add Required Elements**
   - text layers
   - emoji
   - arrows
   - gradients

4. **Style Guidelines**
   - Use bold trendy style
   - Maintain consistent spacing
   - Use brand-appropriate fonts

5. **Export for Selling**
   - File > Download > PDF Print
   - Also export as: PNG (for previews)
   - Save to: /Users/aleckennedy/.openclaw/workspace/outputs/templates/youtube_thumbnail/
