## Step 3: CapCut Instructions

### Template Setup (Do This Once)
1. Download **CapCut** (free)
2. Create project → **9:16 ratio** (vertical)
3. Import script as voiceover
4. Add captions (auto-generate)
5. Add trending music (lower volume under voice)

### Quick Edit Formula
**Every video follows this:**
- **0-3s:** Hook text (big, bold)
- **3-30s:** Main content (your voiceover + B-roll)
- **30-45s:** CTA + your face (builds trust)
- **Captions:** Always on (80% watch without sound)

### Resources to Download
- **Stock footage:** Pexels.com (free)
- **Music:** TikTok trending sounds (in app)
- **Screen recording:** Built into Mac (Cmd+Shift+5)
