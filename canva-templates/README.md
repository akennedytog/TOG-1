# Canva Template Generator

Automated template creation for social media marketing.

## Platforms
- **Instagram**: 1080x1080px, 1080x1920px (Stories/Reels)
- **LinkedIn**: 1200x627px (landscape), 1080x1350px (portrait)
- **Pinterest**: 1000x1500px (2:3 ratio)

## Brand Guidelines
- Primary: #1DA1F2 (Twitter Blue)
- Secondary: #0A0A0A (Dark)
- Accent: #FFD700 (Gold)
- Fonts: Inter (headlines), Open Sans (body)
- Logo: The One Group AI wordmark

## Template Types
1. **Quote Cards** - Thought leadership
2. **Data Cards** - Statistics and metrics
3. **Tips Cards** - Actionable advice
4. **Behind-the-Scenes** - Building in public
5. **CTA Cards** - Lead generation

## Output Formats
- PNG (export)
- JSON (Canva import)
- Markdown (content brief)

## Usage
Templates auto-generated weekly and queued for Canva import.
