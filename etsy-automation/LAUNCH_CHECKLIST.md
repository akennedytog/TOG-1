# Etsy Shop Launch Checklist

## Pre-Launch (Do Today)

### Account Setup
- [ ] Create Etsy account at www.etsy.com/sell
- [ ] Choose shop name (see options in etsy_setup_guide.md)
- [ ] Verify email
- [ ] Connect bank account
- [ ] Add credit card for fees

### Shop Configuration
- [ ] Upload shop banner (1200 × 300px recommended)
- [ ] Upload shop icon (500 × 500px)
- [ ] Write shop announcement
- [ ] Fill "About" section
- [ ] Add shop policies (copy from guide)

### Listing Upload (15 listings)
For each listing:
- [ ] Upload hero photo
- [ ] Add title (from listing_copy.md)
- [ ] Add description (from listing_copy.md)
- [ ] Set price (from pricing table)
- [ ] Add 13 tags (from guide)
- [ ] Set personalization instructions
- [ ] Enable "Request customization"
- [ ] Set processing time: 3-5 days
- [ ] Set shipping profile

Order to upload:
1. TB-01 → TB-06 (Tumblers)
2. CB-01 → CB-04 (Cutting Boards)
3. PT-01 → PT-03 (Pet Tags)
4. WD-01 → WD-02 (Wedding)

### Automation Setup (After first sale)
- [ ] Create Make.com account
- [ ] Connect Etsy webhook
- [ ] Create Google Sheet: "LaserPecker Orders"
- [ ] Test automation with fake order

## Post-Launch (This Week)

### Marketing
- [ ] Share shop on personal social media
- [ ] Create Instagram account for shop
- [ ] Post first product photo
- [ ] Tell friends/family for initial reviews

### B2B Outreach (Parallel)
- [ ] Upload 3,800 leads to Apollo/Instantly
- [ ] Send first batch of realtor emails
- [ ] Follow up with wedding planners

### Operations
- [ ] Order packaging supplies
- [ ] Set up shipping station
- [ ] Print care cards
- [ ] Test engraving workflow

## Ongoing (Daily/Weekly)

### Daily
- [ ] Check for new orders (Etsy + Make notification)
- [ ] Send proof requests for new orders
- [ ] Approve customer revisions
- [ ] Check messages

### Weekly (Per Production Schedule)
- Monday: Tumblers batch
- Tuesday: Pet tags + Wedding items
- Wednesday: Cutting boards
- Thursday: Bundles
- Friday: Corporate/bulk orders
- Saturday: Content + catch-up
- Sunday: Admin + planning

## Quick Reference

**Shop URL:** https://www.etsy.com/shop/[YOUR_SHOP_NAME]
**Listing Fee:** $0.20 per listing (4-month renewal)
**Transaction Fee:** 6.5% + 3% + $0.25
**Profit Margin:** 65-80% (see pricing table)
