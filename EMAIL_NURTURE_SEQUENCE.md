## 🛠️ SETUP INSTRUCTIONS (All FREE)

### Option 1: Gmail + Boomerang (Free Tier)

**Step 1:** Install Boomerang for Gmail
- Go to: https://www.boomeranggmail.com
- Add to Chrome
- Free tier: 10 scheduled emails/month

**Step 2:** Schedule Follow-Ups
- After sending audit report, click "Schedule"
- Set Email 2 for 3 days later
- Set Email 3 for 7 days later
- etc.

### Option 2: Mailchimp (FREE up to 500 contacts)

**Step 1:** Create Account
- Sign up at mailchimp.com
- Use free tier (500 contacts, 1,000 emails/month)

**Step 2:** Create Automation
- Automations → Create → Welcome Series
- Trigger: "Tag added: AI Audit Lead"
- Add 5 emails with delays

**Step 3:** Add Formspree Integration
- When lead submits audit, Mailchimp gets webhook
- Auto-adds to sequence
