## How It Works

### 1. AI Seeds the Data
- Scrapes official sources (MiamiMusicWeek.com, RA, Songkick)
- Creates initial event database
- Publishes the HTML page

### 2. Community Adds Events
- Anyone submits via Google Form
- Submissions include: Event name, venue, date, time, price, ticket link
- 24-hour review process (AI + human verification)

### 3. Live Updates
- New events added daily
- Page timestamp shows last update
- Twitter bot announces new events

### 4. Data is Open
- Public Google Sheet with all events
- CSV export available
- JSON API for developers
